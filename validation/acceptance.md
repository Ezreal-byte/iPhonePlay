# iPhonePlay 0.1.1 验收记录

日期：2026-10-21。此记录区分源码实现、自动化验证与实机验收，未测项不视为通过。

## 已通过

- 用户明确反馈真实 iPhone 的 **AirPlay 投屏、手机声音、截图、录制、全屏** 已验证通过。
- 2026-10-21 用户在 0.1.1 复测确认：手机出现在待确认列表，完成应用内确认后键鼠正常，F9 释放正常。
- Rust 格式检查、全 targets Clippy（warnings 视为错误）：通过。
- Rust 普通测试：库 45 项、界面／悬浮几何 9 项通过；6 项环境测试默认忽略，各自已有显式执行记录。首次完整验证日志：`build/validation/rust-20261021-162029.log`；最终增加 3 项窄窗与弹窗回归后，格式、全目标 Clippy 和 54 项普通测试再次通过。
- 原生 CTest 12 项通过；实际 ABI 18 加载及独立无线接收服务启动／停止通过。
- 实际 FFmpeg 合成视频／音频往返、原帧 PNG 解码及真实编码器失败保留诊断：2 项通过。
- 实际 WinRT GATT HID 广播启动／停止通过。Windows 先发 `Aborted/Success (3/0)`，随后发 `Started/Success (2/0)`；旧 Rust 代码过早停止广播，现已修复并增加回归测试。测试时客户端订阅为空，不能据此宣称键鼠操作通过。
- 无 Git 元数据的源码归档实际重建原生层通过，950 个固定上游文件校验和 7 项归档故障检查通过。
- 0.1.1 非控制中失焦保留配对状态、订阅后手动确认、真实控制中释放及断线不转控等回归通过；真实广播再次记录 `3/0 → 2/0`。只读诊断发现 iPhone 的 Classic 和 BLE 配对记录，测试时仍无 HID 客户端订阅。
- 独立悬浮窗口的实际隐藏 HWND 创建、预览重新挂载、关闭请求与返回、析构保护、圆角区域更新／清除通过。此项验证窗口生命周期，不代替真实视频显示验收。
- 新外观图片、Logo、主题图标及布局已检查实际 egui 渲染截图；明暗主题与 960×640、200% 应用缩放有证据，详见 `design-qa.md`。

详情见同目录 `native-tests.md`、`media-tests.md`、`control-tests.md`、`source-archive.md`，视觉证据见项目根 `design-qa.md`。

- 蓝牙反控在 Alt-Tab、设置、托盘及断线后的远端按键释放；不同适配器兼容性与长时间稳定性。基本键鼠和 F9 已由用户确认通过。
- 真实投屏的圆角显示、悬浮窗口置顶／关闭返回，以及录制中移动画面后的连续性。
- USB 投屏完整流程、驱动缺失与修复、兼容模式。
- 两种来源各 20 次启停、旋转、断线恢复；各 30 分钟录制及内容音画偏差 ≤150ms。
- 真实权限拒绝、磁盘耗尽、封装 120 秒超时、无线宿主异常退出恢复。
- Windows 10 22H2／Windows 11 干净环境安装、运行、卸载；真实系统 100%、125%、150%、200% DPI 和跨屏切换。

本机系统 DPI 为 150%；截图另外覆盖应用内缩放和小窗口。应用缩放检查不冒充系统 DPI 切换验收。安装包编译成功不等于干净系统安装验收通过。
